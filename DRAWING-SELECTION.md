# Drawing preview and marquee selection — source fix

The live drawing draft had no id; an empty selection also had no id. Comparing those empty strings painted a gold selection rectangle around every unfinished stroke. The renderer now requires a real nonempty object id and Select mode before painting selection outlines or resize handles. It never adds that outline to a live freehand, line, rectangle, ellipse or text draft. Actual rectangle artwork and its chosen border still render normally.

In Select, drag empty board space to box-select drawings on the active layer. Lines and freehand strokes use their actual segments, avoiding false hits in empty areas of their bounds. Rectangles, circles and text use their bounds. Players box-select only their own drawings; the DM may select drawings on the active layer. Tokens, custom items, walls and lights are excluded from marquee selection. Click a single drawing to retain existing move/resize/edit behavior. Existing text appearance editing retains its selected target when opening Text controls.

Backspace or Delete removes the selection. A group is one host-validated `delete_many` request, one revision and one undo step. The server validates every id and owner before deleting anything. Stale/duplicate/malformed ids, foreign ownership, non-drawing objects, concealed maps and wrong token-bound maps fail without partial deletion. Ctrl+Z restores the entire group in the original drawing order; insufficient capacity or conflicting restored ids leave undo unchanged. Undo history stays session-local and has count/aggregate memory bounds.

Escape cancels the box and clears selection. Empty click clears selection. Space-drag and middle mouse continue to pan; token dragging/right-click waypoints and Shift-click pings retain their existing routes. Item context menus cannot interrupt an active selection box. Scene/view/role changes clear selection. During real-RPC testing, simultaneous disconnects exposed an existing ENet presence-send race; presence broadcasts now skip disconnected peers/closed channels, matching the existing snapshot guard.

Verification: `tests/drawing_selection.gd` uses native frame readback to check the absence of a live-stroke gold outline, actual focused Backspace input, forward/reverse marquees, grouped undo/z-order, panning, cancellation, text-edit preservation and permission checks. `tools/test_drawing_selection_network.py` uses three isolated authenticated processes to exercise real group-deletion/undo RPCs and an atomic mixed-owner rejection. `token_routes` and `sidebar_stability` cover adjacent movement and native UI behavior. Evidence: `qa/drawing-selection/verified.json` and `qa/source-checks/drawing_selection/*.png`.

No new portable or GitHub release was made for this source change. Published Beta 0.3.21 remains immutable; a new version/build is required to ship it.
